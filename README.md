# Bandar TV 📺 | بندر تي في

## واجهة Home الأساسية — الهدف الرئيسي
هذا المشروع **مشغّل الشاشة الرئيسية (Launcher)**، وليس مجرد تطبيق لعرض واجهة داخلية.
- عند تثبيت APK، يسجّل نفسه كمرشح لنظام **Home** عبر `MAIN + HOME + DEFAULT` مع الاحتفاظ بأيقونة Android TV لاختباره كتطبيق قبل اختياره.
- من **الإعدادات → معلومات الجهاز → اختيار واجهة Home** يمكن طلب شاشة الاختيار الرسمية من النظام، إن كانت مدعومة.
- تظهر **التطبيقات المثبتة فعلياً** على التلفزيون ضمن الصفحة الرئيسية والتطبيقات، ويمكن فتحها بأزرار الريموت، مع الاحتفاظ بالبيانات محلياً.
- اضغط زر **Home** بعد اختياره لتعود إلى Bandar TV بدلاً من الواجهة الأصلية، إذا كان نظام التلفزيون يسمح بمشغّل بديل.
- بعض Google TV / Android TV المخصصة من الشركة المصنعة تمنع اختيار واجهة Home أخرى بشكل طبيعي؛ لا تعطل مشغل الشركة، ولا تستخدم أوامر ADB لتغييره قبل توفير طريقة استرجاع واضحة واختبار توافق جهازك.
- **لا يستطيع GitHub أو Codex تثبيت APK تلقائياً على تلفزيونك** دون ربط محلي وصلاحية الجهاز.


مشروع واجهة تلفزيون عربية مخصصة لتلفزيونات **Android TV وGoogle TV**، بتصميم أصلي داكن مستوحى من أفق الرياض.

## الحالة
**نسخة أولية قابلة للتطوير.** تدعم شاشة رئيسية عربية، والتنقل بين التطبيقات والأقسام، والمفضلة، وتغيير ألوان الواجهة، ولعبة أحرف، والساعة والطقس ومواقيت الصلاة (تحتاج الشبكة). تم تجهيز مشروع Android Studio ويبني تطبيقاً يعرض الواجهة المحلية. لا تدعي هذه النسخة توفير قنوات مدفوعة أو تشغيل أفلام، ولا تعِد بأنها مشغل الشاشة الرئيسية الافتراضي قبل اختبار ذلك على جهازك.

## تجربة الواجهة
افتح [index.html](index.html) في المتصفح. استخدم الأسهم وEnter وEsc أو الماوس.

## الحصول على ملف APK تلقائياً
1. افتح [GitHub Actions](../../actions/workflows/build-android-tv.yml).
2. افتح تشغيل **Build Android TV APK** الأخير الناجح. إن لم يوجد تشغيل ناجح، اضغط **Run workflow**.
3. نزّل ملف **BandarTV-debug-apk** من قسم **Artifacts** (يتطلب الدخول لحساب GitHub).
4. فك الضغط؛ ستجد `app-debug.apk`. ثبّته على جهاز Android TV/Google TV تملكه بعد السماح بتثبيت التطبيقات، أو باستخدام ADB إذا كانت ميزة تصحيح الأخطاء مفعّلة.
5. يمكن تشغيله كتطبيق عادي باسم **Bandar TV**. جعله الشاشة الرئيسية الافتراضية يعتمد على نظام التلفزيون وطرازه، ولا ينبغي تغيير إعدادات Home قبل الاختبار.

## البناء في Android Studio
افتح جذر هذا المستودع في Android Studio. المتطلبات: Java 17 وAndroid SDK API 35 وGradle 8.9. شغّل Gradle Sync ثم Build APK(s). التطبيق: `app/build/outputs/apk/debug/app-debug.apk`.

## الملفات
- `index.html`: تجربة متصفح مستقلة (HTML + CSS + JS).
- `app/src/main/assets/index.html`: الواجهة مدمجة داخل APK للعمل محلياً.
- `app/src/main/java/com/bandartv/launcher/MainActivity.java`: WebView وإجراءات أندرويد مثل فتح التطبيقات المثبتة وWi‑Fi.
- `app/src/main/AndroidManifest.xml`: تعريف التطبيق وظهوره في قوائم Android TV.
- `.github/workflows/build-android-tv.yml`: بناء APK تلقائي.
- `AGENTS.md`: خطة التطوير والملاحظات الفنية لمساعد Codex.
