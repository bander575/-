# Bandar TV — بندر تي في 📺

مشروع واجهة تلفزيون عربية خاصة، نسخة أولية تفاعلية مع تطبيق Android TV.

## تجربة الواجهة
افتح [index.html](index.html) في متصفح الكمبيوتر.

## تحميل APK
افتح **Actions → Build Android TV APK → latest successful run → Artifacts → BandarTV-debug-apk**. إذا فشل البناء افتح سجل الخطأ وأعطِ Codex تعليمات إصلاحه؛ لم يجر اختبار APK على التلفزيون الفعلي.

## فتحه في Codex
اربط مستودع `bander575/-` واقرأ `AGENTS.md` أولاً. طوّر التطبيق كتطبيق Android TV حقيقي واحتفظ بالتصميم العربي الحالي؛ شغّل اختبارات البناء، ثم جهّز APK قابلًا للتثبيت على التلفزيون.

## القيود الحالية
قوائم الأفلام والقنوات تجريبية وليست بثاً، وفتح التطبيقات المثبتة يحتاج تنفيذ وربط Android APIs. لا يمكن افتراض أن Android TV يسمح باستبدال الشاشة الرئيسية آلياً. إضافة المصادر أو الخدمات تتطلب ترخيصاً مناسباً.
